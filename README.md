# SIG_ReceiptGEN
This receipt generator is an open source project which shall help small businesses to generate infinite number of receipts wityh some features like an integrated SIG logo and Watermark and an order no. generator with a certain invoice no. which you can use to track down your usage. Hope you use it sensibly.
The features of this are:
1. Infinite number of Receipt generation
2. Randomized order numbers
3. Serial invoice numbers
4. Downloadable pdf receipts
The informations of this generator are:
1. This generator is having a watermark of the SIG, the creator of this.
2. the receipt will have the name of SIG as the header, you have to put your company's name in the company name section.
   Keep in mind:
   1. Write your company's name in the Company-Name section.
   2. The order no. will have the letter array: "SIG" in the front
   3. If any glitches are found please notify me at : fanmail.cartergmg@gmail.com
